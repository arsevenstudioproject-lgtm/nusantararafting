CATATAN PENTING:
- Aset ini merupakan crop dari satu generated UI atlas, bukan file vector atau sprite transparan per objek.
- Crop mempertahankan sebagian latar belakang/efek cahaya dari atlas. Gunakan sebagai visual reference atau lakukan masking/manual cleanup sebelum produksi.
- Teks di dalam gambar adalah raster; untuk UI final, sebaiknya buat ulang teks dan angka sebagai HTML/CSS atau canvas text agar tajam dan mudah dilokalisasi.
- Ukuran dan posisi crop disusun untuk memudahkan pemisahan awal, bukan sebagai sprite metadata siap-engine.
